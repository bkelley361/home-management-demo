# Feature backlog

The current demo app runs 100% locally with an in-memory mock data store and offline simulation for all features.

Existing product features are implemented in the app:
- Vehicle and home asset tracking with warranty and registration details
- Integer-cent expense tracking linked to specific assets or general household
- Local maintenance schedules and parts/specs lookups
- Document attachments and receipts
- Home-scoped recurring reminders with calendar sync and push notifications
- Demo data reset anytime from Settings
